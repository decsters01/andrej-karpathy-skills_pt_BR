# Guia de Localização (pt-BR)

Este fork é **exclusivamente em português brasileiro**. Não há versões alternativas em inglês ou outros idiomas no repositório.

## Arquivos sincronizados (diretrizes Karpathy)

Ao alterar os quatro princípios, atualize todos juntos:

| Arquivo | Função |
|---------|--------|
| `CLAUDE.md` | Instruções para Claude Code / raiz do projeto |
| `.cursor/rules/karpathy-guidelines.mdc` | Regra Cursor com `alwaysApply` |
| `skills/karpathy-guidelines/SKILL.md` | Skill do plugin Claude |
| `.claude-plugin/plugin.json` | Descrição do plugin |
| `.claude-plugin/marketplace.json` | Descrição do marketplace |

## Arquivos de idioma e conteúdo

| Arquivo | Função |
|---------|--------|
| `.cursor/rules/idioma-pt-br.mdc` | Força respostas do agente em pt-BR |

| `EXAMPLES.md` | Exemplos (narrativa pt-BR; código em inglês) |

## Identificadores que NÃO traduzir

Estes permanecem em inglês por compatibilidade com ferramentas:

- Nomes de pastas: `speckit-plan`, `karpathy-guidelines`
- Slash commands: `/speckit-plan`, `/speckit-implement`
- Chaves YAML/JSON: `name`, `description`, `alwaysApply`, `skills`
- Placeholders de template: `[PROJECT_NAME]`, `[PRINCIPLE_1_NAME]`
- Caminhos de arquivo e URLs GitHub
- Nomes de ferramentas do agente: `Shell`, `Grep`, `CreatePlan`
- Código-fonte em blocos de exemplo
